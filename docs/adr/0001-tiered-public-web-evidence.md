# 등급별 공개 웹 근거를 허용한다

공식 홈페이지 근거만 허용하면 유용한 국내 공개 자료가 검색되어도 근거 없음이
과도하게 발생한다. 따라서 제조사·공공기관은 1등급, 편집 책임이 확인되는 국내
주요 사이트는 2등급, 네이버 블로그 같은 사용자 콘텐츠는 3등급으로 분류하고,
1·2등급은 조건을 충족하면 단독 근거로, 3등급은 독립 출처 두 개가 일치할 때만
근거로 채택한다. 이는 근거 범위를 넓히는 대신 출처의 발행 책임과 교차 확인을
요구해 답변 가능성과 신뢰성 사이의 균형을 유지한다.

상충하는 자료는 높은 등급을 우선하며, 같은 등급의 상충이나 최신성 판단 불가는
숨기지 않는다. 적격 근거가 하나도 남지 않을 때만 근거 없음으로 답한다.
