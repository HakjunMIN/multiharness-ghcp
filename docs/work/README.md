# Local work items

이 디렉터리는 비어 있는 상태로 시작합니다. 참가자가 기능별 root를 직접
만듭니다.

```text
docs/work/<feature>/discovery.md
docs/work/<feature>/spec.md
docs/work/<feature>/tickets/<NN>-<slug>.md
docs/work/<feature>/defects/<NN>-<slug>.md
```

- `discovery.md`는 [Lab 1](../labs/lab1-discovery.md)의 Copilot 발견 세션이 만듭니다.
- `spec.md`와 `tickets/`는 [Lab 2](../labs/lab2-spec-tickets.md)의 Claude 기획 세션이 만듭니다.
- `defects/`는 [Lab 6](../labs/lab6-verification.md)의 Codex 검증 세션이 만듭니다.

규약과 상태 값은 [local work item tracker](../agents/issue-tracker.md)를 따릅니다.
