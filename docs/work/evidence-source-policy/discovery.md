# 근거 출처 정책 발견 결정

Status: decided

## 세션

- Date: 2026-09-08
- Host/harness/model/skill: GitHub/Copilot coding agent/unspecified/domain-modeling

## 문제

공식 홈페이지만 근거로 인정하면 공개 웹에 유용한 국내 자료가 있어도 상담 앱이
지나치게 자주 근거 없음으로 답한다. 근거 없는 주장을 허용하지 않으면서 네이버
블로그와 국내 주요 사이트의 자료를 활용할 수 있어야 한다.

## 승인된 결정

### 출처 등급

| 등급 | 출처 | 채택 조건 |
| --- | --- | --- |
| 1등급 | 제조사, 공공기관 등 사실에 직접 책임지는 1차 출처 | 질문과 관련된 내용을 직접 확인할 수 있으면 단독 근거로 채택한다. |
| 2등급 | 편집 책임이 확인되는 국내 주요 포털, 언론, 전문 사이트 | 발행 주체, 게시 또는 갱신일, 원문 링크를 확인할 수 있으면 단독 또는 보조 근거로 채택한다. |
| 3등급 | 네이버 블로그 등 작성자 게시형 사용자 콘텐츠 | 같은 주장을 뒷받침하는 독립 출처가 두 개 이상일 때만 채택한다. 전재·복제 게시물은 하나로 센다. |

사이트의 유명세만으로 등급을 올리지 않는다. 작성자나 발행 주체, 날짜, 원문
링크, 질문과 직접 관련된 내용을 확인할 수 없는 자료는 근거 후보에서 제외한다.

### 상충과 최신성

- 가격, 재고, 제품 사양, 보증처럼 바뀔 수 있는 사실은 게시 또는 갱신일을 확인한다.
- 적격 근거끼리 상충하면 더 높은 출처 등급을 우선한다.
- 같은 등급이 상충하거나 어느 내용이 최신인지 확인할 수 없으면 단정하지 않고
  상충 사실을 답변에 알린다.
- 낮은 등급의 자료로 더 높은 등급의 최신 정보를 덮어쓰지 않는다.

### 근거 없음과 citation

- 검색 결과의 존재 여부가 아니라 적격 근거의 존재 여부로 근거 없음을 판단한다.
- 적격 근거가 하나라도 있으면 그 범위 안에서 답하고, 뒷받침되지 않는 내용은
  추가하지 않는다.
- 적격 근거가 전혀 없을 때만 근거 없음으로 답한다.
- 답변에 사용한 모든 출처는 제목, 링크, 발췌와 출처 등급을 구조화된 citation으로
  표시한다.

## 제약

- `POST /api/consult`의 시작 `question` 필드와 응답 `answer` 필드는 바꾸지 않는다.
- 실제 APIM 값이나 고객사를 식별할 수 있는 정보는 문서, 로그, fixture에 남기지 않는다.
- 기본 unit/contract test는 네트워크를 사용하지 않고 실제 APIM 검증은 `e2e`
  marker로 분리한다.
- 이 문서는 정책 결정만 기록하며 production implementation은 변경하지 않는다.

## 의존성

- 운영자는 Web Knowledge Source가 공식 홈페이지 외의 적격한 국내 공개 웹 자료도
  검색하도록 구성해야 한다.
- 향후 spec은 citation의 출처 등급 표현과 근거 없음·상충 상태를 관찰 가능한
  API/UI 동작으로 구체화해야 한다.

## 열린 질문

없음. 2등급은 고정 도메인 이름이 아니라 편집 책임과 출처 메타데이터 확인
가능성으로 판정하며, 3등급은 독립 출처 두 개라는 추가 조건을 적용한다.
