# 워크샵 평가 루브릭

팀별 20점 만점이다. 각 항목은 결과물과 실행 근거로 평가하며 발표 품질은 점수에 포함하지 않는다.

| 영역 | 0점 | 1점 | 2점 | 3점 | 4점 |
|---|---|---|---|---|---|
| 요구사항·결정 | 기록 없음 | 질문만 있음 | 대안 또는 근거 부족 | 결정과 근거가 Issue에 있음 | `docs/spec.md`와 Issue가 일치하고 수락 기준이 실행 가능 |
| 아키텍처·작업화 | 작업 구분 없음 | 큰 작업 하나 | task는 있으나 의존성 불명확 | frontier가 유효 | `docs/plan.md`, task, blocker, frontier가 일치 |
| 구현·TDD | 테스트 실패 | 테스트 사후 작성 | 일부 red-green 근거 | 단위 테스트와 known-gap 전환 완료 | task별 세션·커밋·검증 근거까지 추적 가능 |
| 독립 UAT | 자기 검증 | 새 세션만 사용 | 고정 기준 일부 실행 | 모든 고정 UAT 판정 | 구현과 다른 축, 결함 Issue, 커밋된 UAT 보고서까지 완료 |
| HANDOFF·운영 | 브리프 없음 | 필드 누락 | 브리프는 있으나 재현 불가 | 계약 필드와 커밋 artifact 충족 | 다음 세션이 구두 설명 없이 5분 안에 재현 |

## 통과 기준

- 총점 14점 이상
- 독립 UAT와 HANDOFF 영역 각각 3점 이상
- 고객사 식별 정보 또는 비밀 정보가 산출물에 없을 것

## 강사 기록

각 팀의 map Issue URL, 최종 커밋, UAT 보고서, 가장 큰 인수인계 실패 한 건을 기록한다.
